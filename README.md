# Infinite Sudoku

Write any number, anywhere on an endless ruled page. The game will zoom out across the infinite grid and prove it was already written somewhere else.

Almost always.

**Play:** open `index.html` in a browser, or visit the GitHub Pages link for this repo.

- Click anywhere to place your cursor, type digits, press Enter.
- Drag or scroll to move around the page.
- Every trip takes a little longer than the last one.
